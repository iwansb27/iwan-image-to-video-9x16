# IWAN Image to Video 9:16

Browser-local image-to-video creator for Android and desktop browsers.

## Features
- 1–5 images
- 9:16, 4:5, 1:1, 16:9
- 5, 8, 10, 15, 20, 30 seconds
- Full image visible with original aspect ratio preserved
- Animated zoom/pan motion over a filled background
- Large horizontal moving image bands at top and bottom
- Optional rotating round logo
- Silent MP4 export using WebCodecs + mp4-muxer
- No login, database, or server-side upload

Open the GitHub Pages site after Pages is enabled for the repository.
